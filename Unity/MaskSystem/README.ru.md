# MaskSystem (Unity)

**Namespace:** `Vortex.Unity.MaskSystem`
**Сборка:** `ru.vortex.unity.masksystem`
**Статус:** экспериментальный — API и поведение инспектора могут меняться без сохранения совместимости.

## Назначение

Слой Unity для масок ядра (`ru.vortex.core.masksystem`, см. README ядра — синтаксис и гарантии там).

- `UnityWildcardMask`, `UnityRegexMask` — маски для инспектора. Семантика сопоставления не меняется; в редакторе (включая Play Mode) правка параметров перевалидирует маску на лету, в сборке изменение после валидации — ошибка программиста.
- `[MaskSelector]` — выбор типа маски выпадающим списком (в Odin нет выбора типа с фильтром для `[SerializeReference]`).

## Зависимости

- `ru.vortex.core.masksystem`
- Odin Inspector (drawer)

## Использование

```csharp
[SerializeReference, MaskSelector] private Mask urlMask;

private void Init()
{
    var validation = urlMask.Validate();
    if (!validation.IsValid)
        throw new InvalidOperationException(validation.Message);   // fail-fast при инициализации потребителя
}
```

## Инспектор

Поле с `[MaskSelector]` рисуется так:

1. Выпадающий список типов: наследники типа поля, объявленные вне сборки ядра (`UnityWildcardMask`, `UnityRegexMask`, проектные маски). Реализации ядра не предлагаются; если такая назначена кодом — предупреждение.
2. Параметры маски. Наведение на поле шаблона показывает правила синтаксиса выбранной реализации.
3. Ошибка шаблона — красным блоком с сообщением и позицией (`▸` отмечает место).
4. «Тестовая строка» — только для редактора, не сохраняется. Показывает «совпало / не совпало» и захваты.

## Ограничения

- Атрибут работает с одиночным полем типа `Mask` (или наследника). Для списков — оборачивайте маску в элемент-класс с полем `[SerializeReference, MaskSelector]`.
- Тип в списке должен быть не абстрактным, `[Serializable]` и иметь конструктор без параметров.
- Тестовая строка хранится в drawer'е и сбрасывается при перезагрузке домена.
