# MaskSystem (Core)

**Namespace:** `Vortex.Core.MaskSystem`
**Сборка:** `ru.vortex.core.masksystem`
**Статус:** экспериментальный — API и синтаксис шаблонов могут меняться без сохранения совместимости.

## Назначение

Маска — правило сопоставления строки. Нейтральна к домену: работает с любыми строками (URL, пути, ключи), нормализацию входа выполняет потребитель.

- Проверка: строка → `bool` (`IsMatch`)
- Выполнение: строка → признак совпадения + словарь захватов «имя → значение» (`Match`)
- Проверка собственного шаблона: результат, сообщение, позиция ошибки (`Validate`)
- Совпадение всегда со **всей** строкой
- Две реализации: шаблон со `*` (`WildcardMask`) и регулярное выражение (`RegexMask`)

Слой Unity (`ru.vortex.unity.masksystem`) добавляет выбор маски в инспекторе, подсказки, подсветку ошибок и тестовую строку.

## Зависимости

Нет (только `System.Text.RegularExpressions`).

## Использование

```csharp
var mask = new WildcardMask { pattern = "https://{host}.partner.com/v{ver}/**" };
var validation = mask.Validate();            // потребитель — при своей инициализации
if (!validation.IsValid)
    throw new InvalidOperationException(validation.Message);

mask.IsMatch("https://cdn.partner.com/v2/items/5");   // true
var match = mask.Match("https://cdn.partner.com/v2/items/5");
// match.IsMatch == true; match.Captures: host = cdn, ver = 2
```

## Модель

```
Mask (abstract)
├── pattern : string            ← шаблон, синтаксис по реализации
├── caseSensitive : bool = true ← регистр влияет только на сравнение; захваты — в регистре входа
├── Validate() → MaskValidation { IsValid, Message, Position }
├── IsMatch(string) → bool
└── Match(string)  → MaskMatch { IsMatch, Captures : IReadOnlyDictionary<string,string> }

WildcardMask : Mask   + separator : char = '/'
RegexMask    : Mask
```

## Синтаксис `WildcardMask`

| Элемент | Смысл | В результате |
|---|---|---|
| литерал | посимвольно | — |
| `*` | ноль или более символов внутри сегмента | нет |
| `**` | ноль или более любых символов, включая разделитель | нет |
| `{name}` | один или более символов внутри сегмента | `name` |
| `{*name}` | ноль или более любых символов; только последним | `name` |
| `{{` `}}` `\*` `\\` | литералы `{` `}` `*` `\` | — |

- Литералы и захваты в одном сегменте допустимы: `v{ver}`, `{name}.png`.
- При неоднозначности внутри сегмента левый захват жадный: `{a}.{b}` на `x.y.z` → `a = x.y`, `b = z`.
- Невалидно: пустой шаблон, незакрытая или лишняя скобка, `{}`, повтор имени, `{*name}` не в конце, два захвата подряд (`{a}{b}`), неизвестное экранирование, разделитель — служебный символ (`*` `{` `}` `\`) или не задан.

## Синтаксис `RegexMask`

Регулярное выражение .NET.

- Привязка к границам неявная и охватывает выражение целиком: `a|b` не совпадает с `xa`.
- Именованная группа → ключ по имени; неименованная → ключ-номер (`"1"`, `"2"`…).
- Группа 0 и группы, не участвовавшие в совпадении, в результат не входят.
- Невалидно: пустой шаблон; выражение не компилируется (проверяется до обёртки привязкой, поэтому `a)|(b` не «чинится» обёрткой).

## Гарантии и ограничения

- `IsMatch(s) == Match(s).IsMatch` для любой строки.
- Нет совпадения → словарь захватов пуст.
- Невалидная маска не используется: `IsMatch`/`Match` бросают `InvalidOperationException`. `null` на входе — `ArgumentNullException`. Пустая строка — обычный вход.
- После первой сборки (`Validate`, `IsMatch` или `Match`) параметры маски неизменны: изменение обнаруживается при следующем обращении и даёт `InvalidOperationException`. Наследник может разрешить перевалидацию (`RebuildOnChange`) — так делает слой Unity в редакторе.
- Только главный поток.
- Без `RegexOptions.Compiled`: работает на AOT-платформах (IL2CPP, WebGL).
- Списки масок (порядок проверки, «первая подходящая») — ответственность держателя списка.
