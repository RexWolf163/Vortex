# AudioAdvancedControl

**Namespace:** `Vortex.Sdk.AudioAdvancedControl.*`
**Сборка:** `ru.vortex.sdk.audio.advancedcontrol`

---

## Назначение

Управляемый выгружаемый игровой звук: музыка и звуковые петли, привязанные к жизни объекта. Клип загружается перед запуском и уходит из памяти после останова.

- **Два хэндлера:** `AdvancedMusicHandler` (слот cover-музыки) и `AdvancedSoundHandler` (обычный звук с каналом громкости).
- **Список клипов за `AssetHandle<AudioClip>`** — в памяти только клип играющего трека.
- **Три режима:** выбранный трек в цикле, случайный с антиповтором, один раз.
- **Управление из `UIStateSwitcher`:** публичные методы под `EventFire`.
- **Две паузы:** игры и ручная.

Вне ответственности:

- **Короткие общие звуки** (клики UI, эффекты) — это `AudioSystem` и записи базы звуков.
- **Громкость и высота отдельного клипа** — не настраиваются.
- **Выбор, что и когда играет** — решает тот, кто включает объект или зовёт методы.

Когда использовать: звук принадлежит подгружаемому контенту (катсцена, сцена, мини-игра) и не должен оставаться в памяти после него. Записи базы звуков из памяти не выгружаются.

## Использование

Повесить хэндлер на объект контента и заполнить список клипов.

| Поле | Назначение |
|---|---|
| `clips` | список хэндлов клипов |
| `mode` | режим проигрывания |
| `autoStart` | запускать при включении объекта; по умолчанию включено |
| `channel` | канал громкости — только у `AdvancedSoundHandler` |

**Музыка катсцены:** `AdvancedMusicHandler` на корне контента с автозапуском.

**Эмбиент фазы:** `AdvancedSoundHandler` в режиме `Index` на объекте, который включает состояние фазы (`GameObjectsSwitch`). Состояние ушло — объект выключился, звук остановлен, клип отпущен.

**Управление из состояния свитчера:** `EventFire` с вызовом метода хэндлера.

```csharp
handler.Play(2);       // трек №2
handler.PlayNext();    // следующий по режиму
handler.Stop();
handler.Pause();
handler.Unpause();
```

## Архитектура

```
Handlers/
  AdvancedAudioHandler (abstract)  — список клипов, режим, выбор трека, загрузка и отпуск, паузы
  ├── AdvancedMusicHandler         — выход: слот cover-музыки
  └── AdvancedSoundHandler         — выход: обычный звук, канал громкости

Model/
  AdvancedPlaybackMode             — Index / Random / OneShot
```

Пакет состоит из хэндлеров: общего состояния у него нет, шины и контроллера тоже.

### Режимы

| Режим | Поведение |
|---|---|
| `Index` | выбранный трек играет в цикле |
| `Random` | после окончания трека запускается случайный; недавно игравшие не выбираются |
| `OneShot` | трек играет один раз, затем звук останавливается и клип отпускается |

### Выбор трека

Номер текущего трека при включении объекта равен -1. Следующий номер выдаёт один внутренний метод:

- `Index` и `OneShot` — увеличение на единицу, после последнего снова первый;
- `Random` — случайный номер вне истории. История хранит половину списка (округляя вниз) — та же механика, что у звуков базы.

Автозапуск и `PlayNext` идут через него: из -1 первым выпадает трек 0, в `Random` — случайный. `Play(номер)` выставляет номер напрямую.

### Жизненный цикл

```
OnEnable  → номер = -1 → [autoStart] PlayNext
PlayNext / Play(n) → загрузка клипа → запуск
Stop      → останов → отпуск клипа
OnDisable → Stop
```

Отмена загрузки при останове или смене трека — штатная ситуация.

### Пауза

Пауз две, они независимы:

- **пауза игры** — состояние `GameStates.Paused`;
- **ручная** — `Pause()` / `Unpause()`.

Звук играет, только когда нет ни одной. `Unpause()` при паузе игры звук не возобновит.

### Особенности музыки

- **Слот cover-музыки.** Основная тема на время приглушается и возвращается после останова. Громкость — по общим настройкам музыки.
- **Конец трека отсчитывает сам хэндлер.** Слот его не сообщает, поэтому в `Random` и `OneShot` хэндлер считает длительность клипа (паузы не считаются) и действует за время затухания до конца — смена и останов ложатся на штатное затухание аудиосистемы.
- **Смена трека без тишины.** Пока грузится следующий клип, играет прежний.
- **Клип отпускается после затухания**, а не в момент команды.
- **Вытеснение.** Если слот заняла другая музыка, хэндлер замолкает и отпускает клип.

### Особенности звука

- Играет как обычный звук аудиосистемы; громкость — по каналу из поля `channel`.
- Конец трека сообщает аудиосистема. Останов звука с её стороны (например, общая очистка звуков) в режиме `Random` тоже запускает следующий трек.

## Контракт

### Гарантии

- В памяти только клип играющего трека.
- На `OnDisable` звук остановлен, загрузка отменена, клип отпущен (у музыки — после затухания).
- Повторный запуск того же трека не грузит клип заново, если он ещё не отпущен.

### Ограничения

- **Слот cover-музыки один на приложение.** Два музыкальных хэндлера, либо хэндлер и другая система, перебивают друг друга.
- **Зацикленность музыки задаёт источник слота**, а не хэндлер: в `Index` трек зациклен за счёт настройки cover-плеера.
- **Медленная загрузка в `Random` у музыки.** Если следующий клип грузится дольше оставшегося хвоста, прежний трек на мгновение начнётся заново.
- **Останов музыки до её фактического старта.** Аудиосистема запускает cover-музыку с задержкой, пока гасит основную тему. Останов в это окно снимает запуск, но основная тема может остаться приглушённой до следующей смены музыки.

## Граничные случаи

| Ситуация | Поведение |
|---|---|
| Пустой список клипов | `Debug.LogError` при запуске, звука нет |
| `Play(n)` с номером вне списка | `Debug.LogError`, состояние не меняется |
| Элемент списка не задан | `Debug.LogError`, звук останавливается |
| Сбой загрузки клипа, пустой клип | `Debug.LogError`, звук останавливается |
| Объект выключен во время загрузки | загрузка отменяется |
| Запуск во время паузы | трек встаёт на паузу сразу, заиграет после её снятия |
| Один клип в списке, режим `Random` | играет он же |
| `Stop` без играющего трека | ничего |
