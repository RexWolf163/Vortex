# RebindSystem

Sdk-пакет фреймворка Vortex: переназначение клавиш поверх проектного ассета Input System. Команде можно назначить несколько клавиш по группам устройств, конфликты «одна клавиша на несколько команд» проверяются в пределах карты ввода. Изменения игрока хранятся снимком отличий и накладываются на заводскую раскладку при запуске. Ядро — модель, операции, перехват нажатия и события; отдельной сборкой идут готовые вьюшки меню управления.

## Назначение

- Слоты клавиш у каждой команды (экшена Input System) — отдельно по каждой группе устройств
- Проверка конфликтов: внутри карты — отказ со списком, между картами — допускается с подсветкой; общие команды (например, `UI/Click`) — отдельный уровень подсветки против любой карты
- Операции: назначить, забрать клавишу, очистить, обменять, сбросить команду / карту / всё
- Клапан перехвата «нажмите клавишу» с модификаторами Shift/Ctrl/Alt
- Сменные раскладки: взаимоисключающие группы одного устройства
- Снимок отличий с загрузкой по правилам «загруженное — загружено», изоляцией нечитаемого и копией исходника
- Экспорт и импорт снимка — точка отката и массовый ремап
- Правила разработчика в конфиге: разрешённые пары, защищённые, пропускаемые и общие команды, запрещённые клавиши
- Готовые вьюшки: список команд группы, слоты, зона мыши, индикаторы, сброс, переключение раскладки, источник отката для RollbackSystem

Вне ответственности:

- Глифы, локализация названий клавиш, вёрстка меню
- Правило срабатывания пересекающихся бинов (Ctrl, A и Ctrl+A) — внешние обработчики, в том числе `shortcutKeysConsumeInput` Input System
- Надсистемные биндинги (оси, interactions, processors, прочие составные) — система их не видит и не трогает
- Собственные `InputAction`, созданные кодом (например, `KeyboardHandler`), — идут мимо системы

## Архитектура

### Данные

```
InputSystem.actions (заводская раскладка)   RebindSettings (правила)
                 │                                 │
                 └──────────────┬──────────────────┘
                                ▼
                  RebindModel: команды → группы → слоты
                                ▲        │ индекс занятости
               снимок отличий ──┘        ▼
               (драйвер хранения)   AssetWriter ──► InputSystem.actions (слой переопределений)
```

Эффективные биндинги живут только в ассете Input System. Модель — производная от ассета, конфига и снимка, сама не сохраняется. В снимок уходят только отличия от заводского и слоты, назначенные игроком явно.

### Загрузка

`RuntimeInitializeOnLoadMethod` привязывает контроллер к шине и регистрирует процесс в `Loader` (`WaitingFor()` пуст). Драйверы хранения регистрируются сами, `DriverConfig` пропускает только выбранный. В `RunAsync`:

1. чистый лист ассета: снять переопределения и стереть вспомогательные биндинги системы;
2. модель по ассету и конфигу: заводские слоты по группам, пустые слоты до X, активность групп по умолчанию;
3. снимок из хранилища по правилам загрузки (см. «Снимок»);
4. индекс занятости, запись в ассет;
5. `OnReady` открывается, поднимается `OnRebuilt`.

Хэндлеры ввода подписываются на `AppStates.Running`, то есть после загрузки: к первому игровому нажатию переназначения применены.

### Запись в ассет

Заводские биндинги не меняются: изменения ложатся слоем переопределений (`overridePath` не сериализуется). Реальный биндинг добавляется, только если переопределить нечего — слот сверх заводских или смена формы значения (простая клавиша ↔ комбинация). Такие биндинги получают имя `VortexRebind:<guid>`. В редакторе Input System сам переимпортирует ассет при выходе из Play Mode, поэтому в файл ассета ничего не утекает. Неактивная группа и снятая клавиша — переопределение в пустой путь.

## Ключевые концепции

| Концепция | Описание |
|-----------|----------|
| Команда (`RebindCommand`) | Экшен Input System, id — `Карта/Экшен`. Пропускаемая команда слотов не имеет |
| Группа устройств (`DeviceGroupSettings`) | Ключ, layout'ы устройств (с наследованием: `Gamepad` покрывает DualShock, DualSense, XInput), число слотов X, ключ набора переключения |
| Слот (`BindSlot`) | Позиция в списке клавиш команды внутри группы. Адрес — `bindKey`: `Карта/Экшен#Группа#N` |
| Значение (`BindingValue`) | Триггер и 0–2 модификатора — пути контролов. Неизменяемо |
| Сигнатура | Нормализованный ключ сравнения значений: регистр, порядок модификаторов, стороны модификаторов по настройке |
| Индекс занятости | «Группа + сигнатура → слоты». Проверка кандидата без обхода всех биндингов |
| Происхождение (`SlotOrigin`) | `Default`, `Overridden`, `Added`, `Cleared`, `Empty` |
| Конфликт (`SlotConflict`) | `None`, `CrossMap` (другая карта — допустим), `IntraMapAllowed` (разрешённая пара), `IntraMap` (только из загрузки или импорта), `Common` (другая карта, одна из сторон — общая команда — допустим, подсвечивается отдельно). Значения — номера состояний свитчера; тяжесть — см. «Общие команды» |
| Общая команда | Команда из `commonCommands`, действующая поверх любой карты (`UI/Click`). Совпадение её клавиши с другими картами даёт `Common` вместо `CrossMap` |
| Явное назначение (`IsExplicit`) | Слот назначен игроком. Сохраняется, даже если совпадает с заводским; снимается сбросом |
| Клапан (`CaptureValve`) | Состояние «ждём нажатия для слота» |

### Правило обслуживания

Система видит только биндинги, которые назначаются через «нажмите клавишу»:

- одиночный контрол семейства Button или синтетическое направление оси (`up`/`down`/`left`/`right`: колесо мыши, направления стика);
- составной `OneModifier` / `TwoModifiers` / `ButtonWithOneModifier` / `ButtonWithTwoModifiers` с модификаторами Shift/Ctrl/Alt и триггером клавиатуры или мыши.

Биндинги с interactions или processors, оси, прочие составные, usage- и wildcard-пути — надсистемные. Биндинг, чьё устройство не входит ни в одну группу, — тоже.

### Порядок проверки кандидата

Первый провал — `Rejected` с причиной:

1. слот существует: команда, не пропускаемая, группа, индекс < X (`UnknownCommand`, `SkippedCommand`, `UnknownGroup`, `UnknownSlot`);
2. кандидат обслуживаемый: не больше двух модификаторов, модификаторы — Shift/Ctrl/Alt разных семейств (`TooManyModifiers`, `AmbiguousModifiers`, `InvalidTrigger`);
3. устройство входит в группу слота (`DeviceNotInGroup`);
4. не запрещён (`ForbiddenKey`);
5. склейка: та же клавиша у этой команды в группе переезжает в целевой слот;
6. внутрикартовый конфликт без разрешённой пары (`IntraMapConflict` со списком);
7. защищённость — у операций, снимающих клавишу с команды (`ProtectedLastBinding`).

## Критические требования

1. **Биндинги проектного ассета меняет только система.** Правки в обход (`ApplyBindingOverride`, `AddBinding` на `InputSystem.actions`) не отслеживаются: в модель и индекс они не попадают и перекрываются следующей записью системы.
2. **Прямое назначение — обобщёнными путями.** Сигнатура сравнивает пути как строки: `<DualSenseGamepadHID>/buttonSouth` и `<Gamepad>/buttonSouth` для неё разные клавиши. Клапан перехвата обобщает сам; вызывающий `Assign` / `Take` передаёт пути в той же форме.
3. **Драйвер хранения готов синхронно.** Процесс загрузки ни от чего не зависит и читает снимок в `RunAsync`; драйвер с асинхронной инициализацией прочитали бы до готовности.
4. **Заводских биндингов в группе — не больше X.** Нарушение — ошибка в лог при каждом запуске. Первая операция над командой (кроме сброса) отбросит лишние.
5. **Ключ группы — без `#` и `/`.** Он входит в адрес слота.
6. **Одновременно активные пересекающиеся группы вне набора — ответственность разработчика.** Конфликты между группами не проверяются.

## Контракт

### Вход

- Ассет `RebindSettings` (создаётся автоматически, см. «Использование»)
- Проектный ассет Input System (`InputSystem.actions`)
- Драйвер хранения, назначенный `RebindBus` в `DriverConfig`: `RebindPlayerPrefsDriver` или `RebindFileDriver`

### Выход

- Модель `RebindBus.Data`: команды, слоты по группам, активность групп
- Ответ операций — `RebindResult`: статус, причина, конфликты, изменённые слоты
- Состояние клапана `RebindBus.Capture`
- Признаки `RebindBus.CanPersist` (изменения сохраняются) и `HasChanges()` (есть отличия от заводских)
- События шины: `OnSlotsChanged`, `OnRebuilt`, `OnGroupsChanged`, `OnCaptureChanged`
- Снимок в хранилище драйвера и слой переопределений в ассете

### Гарантии

- Одна изменяющая операция — одно сохранение и одно событие. Исключения — `ResetAll` и `Import`: `OnRebuilt`, затем `OnGroupsChanged`
- Операции не создают внутрикартовых конфликтов: `IntraMap` возможен только из загрузки или импорта
- Операция не оставляет защищённую команду без клавиш
- После операции над командой в каждой её группе не больше X клавиш и нет дублей; сброс и загрузка к X не приводят
- Заводские значения ассета не меняются: сброс снимает переопределения
- Загруженное применяется как есть, даже если нарушает правила; приводится к ним при первой операции над командой
- Нечитаемое заменяется заводским по уровням, исходник сохраняется копией перед первой перезаписью
- Прерванный перехват ничего не меняет
- При закрытом клапане подписок на ввод нет

### Ограничения

- **Изменения в обход системы не отслеживаются** (см. «Критические требования»).
- **Повторный запуск без перезагрузки домена не поддерживается.** Модель и ассет собираются с чистого листа, но `OnReady` статический и не переоткрывается — как у остальных шин Vortex.
- **Ошибка чтения хранилища отключает запись до перезапуска.** Содержимое снимка неизвестно, перезаписывать его нельзя; изменения игрока действуют в памяти, `CanPersist` — `false`.
- **`Import` полностью нечитаемого текста возвращает `Applied`.** Остаются заводские настройки; признака деградации в результате нет, только предупреждение в лог.
- **Пока пойманная клавиша зажата, прочие нажатия её устройства гасятся.** Иначе удерживаемая клавиша дошла бы до игры со следующим событием устройства.
- **Из нескольких кандидатов за один апдейт ввода берётся первый.**
- **Отмена перехвата запрещённой клавишей — только без модификатора.** Зажатый модификатор уже проглочен, и события его устройства гасятся: Ctrl+Esc до игры не дойдёт.
- **Конфликты считаются только внутри группы.**

## API Reference

// ── Доступ ────────────────────────────────────────────────────────────────
RebindBus.OnReady.Subscribe(OnRebindReady);    // InitValve: Subscribe / Unsubscribe
bool              RebindBus.IsReady;
bool              RebindBus.CanPersist;        // false — только в памяти: нет драйвера или хранилище не прочиталось
IRebindController RebindBus.Controller;
RebindModel       RebindBus.Data;              // null до загрузки
CaptureValve      RebindBus.Capture;

// ── Операции (bindKey = "Карта/Экшен#Группа#N") ──────────────────────────
RebindResult Assign(string bindKey, BindingValue value);  // внутрикартовый конфликт → Rejected
RebindResult Take(string bindKey, BindingValue value);    // забрать у конфликтующих команд
RebindResult Clear(string bindKey);
RebindResult Swap(string bindKeyA, string bindKeyB);
void ResetCommand(string commandId);
void ResetMap(string map);                                // null — без действия

void SetGroupActive(string groupKey, bool active);        // включение гасит группы своего набора

BindSlot                GetFirst(string commandId, string groupKey);

string                  BindSlot.GetDisplayString();      // «Ctrl+A»; глифы и локализация — вьюшка

// ── Откат ─────────────────────────────────────────────────────────────────

RebindBus.OnGroupsChanged  += () => { };     // активность групп

## Использование

### 1. Включение пакета

В ассете `SdkSettings` включить тумблер `rebindSdk` — добавляется символ `USING_VORTEX_REBIND`.

### 2. Ассет настроек

`RebindSettings` реализует `ICoreAsset` и создаётся автоматически в `Assets/Resources/Settings/`. Если автосоздание выключено — `Tools → Vortex → Debug → Check Core Assets`. Быстрый переход к ассету — `Tools → Vortex → Configs → Rebind Settings` (пункт есть только при включённом пакете).

| Поле | По умолчанию | Смысл |
|------|--------------|-------|
| `groups` | `Keyboard&Mouse` (Keyboard, Mouse; X = 2), `Gamepad` (Gamepad; X = 2) | Группы устройств |
| `allowedPairs` | пусто | Пары команд одной карты, которым можно делить клавишу |
| `protectedCommands` | пусто | Команды, у которых операция не снимет последнюю клавишу |
| `skippedCommands` | пусто | Команды вне системы целиком |
| `commonCommands` | пусто | Команды, действующие поверх любой карты: совпадение клавиши с другой картой — `Common` |
| `forbidden` | системные клавиши и сочетания | Запрещённые клавиши: сама клавиша, с конкретным набором модификаторов или с любым |
| `distinguishModifierSides` | выключено | Различать левый и правый модификатор |
| `snapshotFolder` | `Controls` | Папка файла снимка относительно `FileBus.GetAppPath()` |

Дефолт запрещённых: синтетические и перехватываемые ОС клавиши (`anyKey`, `IMESelected`, Win, `contextMenu`, `printScreen`), `numLock`, `scrollLock`, `pause`, `f12` (скриншот Steam), `OEM1`–`OEM5`; любой модификатор + F1–F12, Tab, Enter, NumpadEnter, Esc; Alt+Space.

Защиты, пары, пропуски и общие команды формирует разработчик: по умолчанию списки пусты, встроенных предохранителей нет.

Группа `Gamepad` покрывает всех наследников layout'а: DualShock, DualSense, XInput (в том числе Steam Deck и контроллеры под Steam Input), Switch Pro. Добавление `Joystick` захватывает HID-геймпады и джойстики, не распознанные как `Gamepad`; заводских биндингов у них нет, а пути кнопок привязаны к модели устройства.

### 3. Регистрация драйвера

В ассете `DriverConfig`: **Reload** → для системы `RebindBus` выбрать драйвер → **Save Config**.

| Драйвер | Хранилище | Копия нечитаемого |
|---------|-----------|-------------------|
| `RebindPlayerPrefsDriver` | ключ `VortexRebindSnapshot` | ключ `VortexRebindSnapshot_backup_<yyyyMMdd_HHmmss>` |
| `RebindFileDriver` | `<FileBus.GetAppPath()>/<snapshotFolder>/bindings.json`, атомарная запись | `bindings_<yyyyMMdd_HHmmss>.json` рядом |

Без драйвера система работает только в памяти, в лог пишется ошибка.

### 4. Перехват нажатия

```csharp
private void OnEnable() => RebindBus.OnCaptureChanged += OnCaptureChanged;
private void OnDisable() => RebindBus.OnCaptureChanged -= OnCaptureChanged;

public void OnSlotClicked(string bindKey)
{
    var reason = RebindBus.Controller.SaveSignalForBind(bindKey);
    if (reason != RejectReason.None)
        view.ShowError(reason);
}

private void OnCaptureChanged(CaptureValve valve)
{
    var result = valve.LastResult;
    if (valve.IsOpen)
    {
        view.ShowWaiting(valve.BindKey, valve.HeldModifiers);
        if (result != null)
            view.ShowHint(result.Reason);        // запрещённая клавиша — ждём дальше
        return;
    }

    switch (result.Status)
    {
        case RebindStatus.Applied:  view.Highlight(result.Conflicts); break;   // CrossMap и Common
        case RebindStatus.Rejected: view.OfferTakeOrSwap(result.Conflicts); break;
        case RebindStatus.Cancelled: view.Close(); break;
    }
}
```

Правила клапана:

- ловятся только устройства группы слота; нажатия других устройств работают как обычно;
- нажатия, зажатые в момент открытия, не ловятся, пока не отпущены;
- ловятся кнопки и синтетические направления: колесо мыши, направления стиков; движение указателя (`delta`) не ловится;
- зажатый модификатор ждёт основную клавишу; одиночный модификатор, отпущенный без неё, сам становится клавишей; три модификатора или два, отпущенных без клавиши, — отказ;
- **запрещённая клавиша не перехватывается**: отказ `ForbiddenKey`, нажатие уходит в игру, клапан остаётся открытым. Так работает отмена перехвата клавишей из запрещённых: Esc в чёрном списке доходит до `UICancel`;
- недопустимый триггер — отказ, клапан остаётся открытым; внутрикартовый конфликт и успех закрывают клапан;
- повторный `SaveSignalForBind` перенацеливает клапан; `CancelSaving` и потеря фокуса окна — `Cancelled`;
- кандидат, отклонённый фильтром (`AddCaptureFilter`), игнорируется и уходит в игру и UI;
- пойманное нажатие до игровых команд не доходит;
- путь обобщается до самого общего layout'а, который ещё входит в группу: DualSense в группе `Gamepad` даёт `<Gamepad>/buttonSouth`.

Фильтры постоянные: регистрирует и снимает их вьюшка, клапан применяет все зарегистрированные. Готовый пример — `CaptureMouseHandler` (см. «Вьюшки»).

### 5. Конфликт: забрать или обменять

```csharp
private void OnTake(string bindKey, ConflictInfo conflict)
{
    var value = RebindBus.Data.GetSlot(conflict.OtherBindKey).Value;
    RebindBus.Controller.Take(bindKey, value);
}

private void OnSwap(string bindKey, ConflictInfo conflict) =>
    RebindBus.Controller.Swap(bindKey, conflict.OtherBindKey);
```

### 6. Подсказки клавиш в игре

```csharp
var slot = RebindBus.Controller.GetFirst("Player/Jump", "Keyboard&Mouse");
hint.text = slot?.GetDisplayString() ?? string.Empty;
```

Подписка на `OnSlotsChanged`, `OnRebuilt` и `OnGroupsChanged` держит подсказку актуальной.

### 7. Сменные раскладки

Группы с общим `switchSet` взаимоисключающие: `SetGroupActive(key, true)` выключает остальные группы набора. Бинды неактивной группы не срабатывают, но редактируются, и конфликты в ней считаются. По умолчанию активна первая группа каждого набора и все самостоятельные (без `switchSet`); самостоятельные переключение раскладок не затрагивает.

### 8. Общие команды

Карты обычно не пересекаются: клавиша, общая для команд разных карт, — `CrossMap`, допустимо и подсвечивается, а вёрстка вправе показывать его как `None`. Общая команда действует поверх любой карты — например, `UI/Click` имитирует клик мыши в каждой мини-игре. Внесённая в `commonCommands`, она получает отдельный уровень: совпадение клавиши между картами, где хотя бы одна сторона — общая команда, даёт `SlotConflict.Common` на обоих слотах.

- Только подсветка: операция не отклоняется, как и при `CrossMap`.
- Внутри одной карты действуют обычные правила: `IntraMap` и `IntraMapAllowed` тяжелее.
- `RebindResult.Conflicts` при `Applied` содержит `CrossMap` и `Common`.
- Тяжесть по возрастанию: `None`, `CrossMap`, `Common`, `IntraMapAllowed`, `IntraMap`. Значения enum — номера состояний свитчера (`UIStateSwitcher.Set(Enum)`), поэтому новые члены добавляются только в конец — тяжесть не следует из порядка членов.

В префабе слота у `conflictSwitcher` появляется отдельное состояние `Common`.

## Вьюшки

Сборка `ru.vortex.sdk.rebind.views`, пространство имён `Vortex.Sdk.RebindSystem.Views`.

| Компонент | Назначение |
|-----------|-----------|
| `RebindGroupHandler` | Выводит в `Pool` обслуживаемые команды своих карт для одной группы. Поля: ключ группы, список карт, пул. Данные элемента — команда и группа. Пул перезаполняется по `OnRebuilt` |
| `RebindCommandView` | Элемент пула группы: название команды (шаблон `titlePattern`: `{0}` — id, `{1}` — карта, `{2}` — экшен; проходит локализацию) и вложенный `Pool` слотов группы с индексом < X |
| `RebindSlotView` | Элемент пула слотов: текст клавиши (`GetDisplayString`), свитчеры конфликта (`SlotConflict`, включая `Common`), происхождения (`SlotOrigin`) и ожидания (`SwitcherState`). Публичный `SaveNewKey()` вешается на кнопку и открывает перехват |
| `CaptureMouseHandler` | Зона перехвата мыши: пока включён, клавиши мыши ловятся только при указателе над ним (`IPointerEnter/Exit`), вне зоны мышь уходит в UI. Объект принимает лучи UI и не содержит кнопок |
| `CaptureStateHandler` | Свитчер `SwitcherState`: `On` — клапан ждёт клавишу, `Off` — нет |
| `CaptureCancelHandler` | Публичный `Cancel()` для кнопки «Отмена»; флажок `cancelOnDisable` прерывает ожидание при выключении объекта |
| `SwitchSetHandler` | Переключение раскладки внутри набора: `Next()` / `Previous()` по порядку конфига, название активной группы в `UIComponent`. Пустой ключ набора — ошибка в лог |
| `ChangesStateHandler` | Свитчер `SwitcherState`: `On` — есть отличия от заводских (`HasChanges()`) |
| `ResetToFactoryHandler` | Публичный `ResetAll()` для кнопки «Сбросить всё»; открытый перехват прерывается |
| `RebindRollback` | Источник отката для `RollbackHandler` (пакет RollbackSystem): точка — снимок `Export()`, откат — `Import()`, изменения — по отпечатку модели |

Схема вёрстки меню: панель группы с `RebindGroupHandler` → пул строк на префабе с `RebindCommandView` → вложенный пул слотов на префабе с `RebindSlotView`. Панель перехвата — `CaptureStateHandler`, `CaptureMouseHandler`, `CaptureCancelHandler`.

### Откат изменений

Экран переназначения подключается к RollbackSystem: на `RollbackHandler` экрана добавить источник `RebindRollback`. Точка отката — состояние на момент открытия экрана или последнего «Сохранить», включая активность групп; откат прерывает открытый перехват и возвращает снимок. Снимок сравнивается не по тексту: разделы сжаты ZIP, а записи архива несут время создания — два экспорта одного состояния дают разные строки.

`ChangesStateHandler` и откат отвечают на разные вопросы: первый сравнивает с заводскими настройками, откат — с точкой отката.

## Снимок

Формат — сериализатор Vortex, вложенные разделы хранятся сжатыми строками. Корень — словарь строк без POCO-классов: переименование типов снимок не ломает.

| Уровень | Содержимое | Нечитаем → |
|---------|------------|------------|
| Корень | `version`, `active` (активные группы), `g:<группа>` на каждую группу | всё заводское |
| Раздел группы | команда → раздел команды | группа заводская |
| Раздел команды | список записей слотов | команда в группе заводская |
| Запись слота | `b[e]:<id биндинга>=<значение>` — заводской, `a[e]:<позиция>=<значение>` — добавленный; `e` — назначен явно; значение — `триггер\|модификатор\|модификатор`, пусто — клавиша снята | слот заводской |

Правила загрузки:

- команды, биндинги и группы, которых больше нет, отбрасываются молча;
- если конфиг перенёс заводской биндинг в другую группу, его запись переезжает вместе с ним;
- значение, чьё устройство больше не подходит группе, уходит добавленным слотом в первую подходящую группу;
- нарушения лимитов, запретов и наборов переключения применяются как есть;
- снимок новее формата — полностью заводские;
- при любой нечитаемости исходный текст сохраняется копией перед первой перезаписью; копия не записалась — перезапись откладывается.

Снимок глобальный: не привязан к слоту сейва. Экспорт отдаёт тот же текст; импорт полностью заменяет пользовательское состояние, включая активность групп.

## Граничные случаи

| Ситуация | Поведение |
|----------|-----------|
| Нет ассета `RebindSettings` | Ошибка в лог; групп нет — система ничего не обслуживает |
| Драйвер не назначен в `DriverConfig` | Ошибка в лог, работа только в памяти, `CanPersist` — `false` |
| Хранилище не прочиталось | Заводские настройки, запись снимка отключена до перезапуска |
| Снимок частично нечитаем | Нечитаемое — заводское, копия исходника перед первой перезаписью |
| Заводских биндингов в группе больше X | Ошибка в лог при запуске; первая операция над командой (кроме сброса) отбрасывает лишние |
| Операция до загрузки | `Rejected` (`UnknownSlot`); `Import` — `Cancelled`; сбросы и переключение — без действия |
| `ResetMap(null)` | Без действия: сброс всего — только `ResetAll` |
| `Clear` пустого слота | `Applied` без изменений |
| Защищённая команда теряет последнюю клавишу | `Rejected` (`ProtectedLastBinding`); слоты сверх X в счёт не идут |
| LeftCtrl+RightCtrl+A | `Rejected` (`AmbiguousModifiers`) |
| Запрещённая клавиша при перехвате | Отказ `ForbiddenKey`, нажатие уходит в игру, клапан открыт |
| Внутрикартовый конфликт при перехвате | Клапан закрывается, `Rejected` со списком |
| Потеря фокуса окна при перехвате | `Cancelled`, слот без изменений |
| Команда из `skippedCommands` | Слотов нет, `GetAll` — пусто, операции — `SkippedCommand` |
| Клавиша общей команды совпала с командой другой карты | Оба слота — `Common`; операция применяется |
| Клавиша общей команды совпала с командой своей карты | Обычные внутрикартовые правила: `IntraMap` / `IntraMapAllowed` |
| Команда одновременно общая и пропускаемая | Ошибка валидации конфига: у пропускаемой нет слотов |
