# CutsceneSystem — примеры контента

> ⚠️ **Экспериментальный пакет** — спутник [CutsceneSystem](../../Unity/CutsceneSystem/README.ru.md), который не прошёл обкатку в продуктовой эксплуатации. Структура примера префаба может измениться вместе с ним без обратной совместимости.

**Сборка:** нет — в папке только ассеты

---

## Назначение

Готовая основа префаба контента для [`CutsceneSystem`](../../Unity/CutsceneSystem/README.ru.md): катсцена на смене спрайтов с плавным переходом и слотами звука.

Пример лежит в SDK, а не в пакете катсцен: звук в нём — хэндлеры [`AudioAdvancedControl`](../AudioAdvancedControl/README.ru.md), а пакет катсцен слоем ниже про них не знает.

Основа Spine-катсцены лежит в [`SpineExtensions/Cutscenes`](../../SpineExtensions/Cutscenes/README.ru.md).

---

## Состав

```
Example/
  baseSpriteCutscene.prefab   — основа спрайтовой катсцены
  CutsceneCrossFade.asset     — пресет твина перехода: линейная кривая, 0,4 с
```

## baseSpriteCutscene

UI-префаб: корень — `RectTransform`, растянутый на родителя. `target` оркестратора должен быть под канвасом.

```
baseSpriteCutscene   StateGraphView, UIStateSwitcher, TweenerHub
├── [AudioControl]   AdvancedMusicHandler; выключен
└── Layers           выключен; включается состояниями фаз
    ├── current      Image — картинка текущей фазы
    └── old          Image поверх current — картинка прошлой фазы, гаснет на переходе
```

Эмбиента в основе нет: эмбиент фазы — дочерний слой `[AudioControl]` с `AdvancedSoundHandler`, его включает состояние фазы элементом `GameObjectsSwitch` с отложенным выключением.

### Состояния свитчера

| Состояние | Элементы |
|---|---|
| `End` | пусто — состояние конечного узла графа |
| `Phase 1` | `GameObjectsSwitch` (`Layers`, `[AudioControl]`); `SpritesSwitch` → `current` |
| `Phase 2`, `Phase 3` | то же; `SpritesSwitch` → `old` (спрайт прошлой фазы); `EventFire`: `TweenerHub.Forward(true)`, затем `TweenerHub.Back(false)` |

### Переход old → current

- В покое `old` прозрачен и выключен.
- На входе в фазу `current` получает спрайт фазы, `old` — спрайт прошлой.
- `Forward(true)` мгновенно делает `old` непрозрачным: на экране остаётся прошлая картинка.
- `Back(false)` плавно гасит `old` и в конце выключает его (в пресете стоит `offOnStartPoint`). Под ним открывается `current`.
- Первая фаза появляется без перехода: гасить нечего.

Твин перезапускается через `EventFire`, а не `TweenerHubSwitch`: повторный `Forward` на уже отыгравшем хабе ничего не запускает. Перезапуск — это скачок в конец и обратный ход.

`GameObjectsSwitch` фаз стоит с отложенным выключением: между фазами объекты не выключаются, звук не перезапускается.

### Задержка между переключениями

У `StateGraphView` на корне задан `switchDelay` (0,5 с): следующее состояние он выставляет не раньше, чем через эту задержку после предыдущего. Без задержки «дальше» посреди перехода оборвало бы твин, и кадр дал бы скачок яркости.

View про твины не знает. Переход должен уложиться в задержку: в примере твин 0,4 с при задержке 0,5 с. Меняя одно, нужно менять и другое.

Хэндлера контента (`CutsceneContentHandler`) в основе нет: у картинки нет автоперехода, все фазы ждут команды «дальше».

### Своя катсцена

1. Создать вариант префаба (`Prefab Variant`).
2. В состоянии каждой фазы задать спрайт для `current`; для `old` — спрайт фазы, из которой в неё приходят.
3. Новая фаза — новое состояние: свитчер дублирует последнее, остаётся сменить спрайты.
4. Создать граф катсцены (`Database/State Graph`): узел на каждое состояние с тем же именем, включая `End`; фазы связать переходами «по `Next`», последнюю — с `End`. Назначить граф в `StateGraphView`. Кнопка Sync у View сверяет состояния с узлами.
5. На `[AudioControl]` добавить клипы музыкальному хэндлеру. Эмбиент фазы — слоем (см. выше); канал громкости выбирается в его `AdvancedSoundHandler`.
6. Длительность перехода меняется в пресете. Нужна своя — сделать копию пресета и назначить её в `ColorLogic` хаба. `switchDelay` у View должен быть не меньше длительности перехода.

Ход показа задаёт граф. Слот `old` хранит одну картинку, поэтому у фазы, в которую приходят из разных фаз, прошлая картинка совпадёт только с одной из них. Шаги 1–5 умеет делать [фабрика ассетов](../../../Plugins/AssetFactory/README.ru.md); слои эмбиента она заводит и включает сама.

## Граничные случаи

| Ситуация | Поведение |
|---|---|
| У музыкального хэндлера пустой список клипов | автозапуск в основе включён — при включении `Debug.LogError` «Список клипов пуст». Без музыки у хэндлера выключается `autoStart` (фабрика делает это сама) либо он удаляется. Убирать `[AudioControl]` из списков `GameObjectsSwitch` нельзя: в нём же слои эмбиента |
| Для `old` не задан спрайт прошлой фазы | на переходе гаснет белый прямоугольник |
| «Дальше» пришло, пока идёт переход | следующая фаза показывается, когда истечёт `switchDelay`; пришло несколько — показывается сразу последняя |
| Твин перехода длиннее `switchDelay` | следующее переключение обрывает переход: скачок яркости кадра |
| Катсцена завершена, пока фаза ждёт задержку | контент выгружается, фаза не показывается |
| Пропорции картинки и экрана не совпадают | картинка вписывается целиком (`Preserve Aspect`), по краям остаются поля |
